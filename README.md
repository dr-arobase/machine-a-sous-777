Machine à sous - Levier 777

Ce petit projet est une simulation locale d'une machine à sous. L'objectif est d'obtenir 777 pour décrocher le jackpot.

Fichiers:
- index.html : page principale (ouvrez-la dans votre navigateur).
- styles.css : styles de la page.
- script.js : logique de jeu (mises, rouleaux, paiement).

Règles de base:
- Solde initial : 1000 crédits.
- Entrez une mise (>=1) et appuyez sur le levier ou le bouton "Tirer".
- 777 = Jackpot x100 de la mise.
- 3 mêmes chiffres (non-7) = x10.
- 2 mêmes chiffres = x2.

Ouvrir et tester:
Double-cliquez sur `index.html` ou ouvrez-le avec votre navigateur (Chrome/Edge/Firefox). Aucun serveur requis.

Améliorations possibles:
- Ajout de sons, animations plus poussées.
- Historique des parties, sauvegarde locale.
- Options pour ajuster les multiplicateurs et l'équité (probabilités).

Note: C'est une simulation éducative. Ne jouez pas d'argent réel.
